# Perimeter-and-Area-of-a-Rectangle
Python script to calculate the perimeter and area of a rectangle based on user input.

# Perimeter and Area of a Rectangle made by Terex

```
length = float(input("Type length: "))
height = float(input("Type height: "))

perimeter = 2 * (length + height)
area = length * height

print("Perimeter of Rectangle: " + str(perimeter))
print("Area of Rectangle: " + str(area))
```
